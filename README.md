# フクワウチ(FUKUWAUCHI)

> 福を、企業へ。
> 株式会社オニカナが運営するAIビジネスマッチングプラットフォーム。
> 開発:bizmote株式会社

企業の課題と、最適な支援先(Giver)を、5軸AIマッチングで結びます。

## 概要

- **クライアント企業**:無料で利用。課題を登録するとAIが上位10社を提案
- **支援先(Giver)**:アポ1件ごとに役職別単価をオニカナに支払う完全成果報酬モデル
- **管理者(オニカナ)**:KPI・マッチング・請求を一元管理

3つの利用者向け画面で構成され、デモ版はログイン不要で各画面を体験できます。

## 技術スタック

| レイヤー | 採用技術 |
|---------|---------|
| フレームワーク | Next.js 14 (App Router) + TypeScript |
| スタイリング | Tailwind CSS |
| 状態管理 | Zustand(デモ版は localStorage 永続化) |
| グラフ | Recharts |
| ホスティング | Vercel |

> デモ版はバックエンド不要(全データはブラウザ内のモック)。
> 本実装(Phase 2 / 2026年7月〜)で Supabase・認証・Google Calendar連携・メール通知を追加予定。

## ローカルでの起動

```bash
npm install
npm run dev
```

ブラウザで http://localhost:3000 を開く。

## 主な画面

- `/` トップ(3ロールの入口)
- `/client/*` クライアント(アンケート・レコメンド・マッチング・メッセージ・商談)
- `/supplier/*` 支援先(打診・メッセージ・商談・プロフィール・会員登録)
- `/admin/*` 管理者(KPI・企業・マッチング・LIKE・スコアリング)

## ブランドカラー(3色)

- 鬼の朱 `#D8281D` — 支援先・熱意・警告
- 鬼の群青 `#1E4FA3` — クライアント・主アクション・完了
- 福の砂色 `#EBE1C2` — 背景・アクセント
